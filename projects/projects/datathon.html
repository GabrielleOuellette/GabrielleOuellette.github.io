Breast Cancer Imaging Verification

National Canadian Medical Datathon — Advanced Section

Project overview

Created and trained artificial intelligence to scan ultrasound images for breast cancer based on a provided dataset.

My role

Coded the logic behind using a dataset of variables in Python and HTML and helped develop the public-facing website for the project.

The website

Created a website that allows the project to be accessed publicly as a breast cancer imaging verification tool.

Presentation

Presented our proposed idea to a set of judges and medical professionals as part of the National Canadian Medical Datathon.

Engineering focus

This project allowed me to combine artificial intelligence, programming and medical imaging into one project with a healthcare application.
