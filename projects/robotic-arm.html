Medically Assistive Robotic Arm

Dalhousie University · Halifax, NS
January 2026 — April 2026

This project involved designing and programming a medically assistive robotic arm. I worked on both the physical design and the embedded control system behind the arm.

My role: Design the arm and PCB in CAD and develop the C++ control logic in Microchip Studio.

Design

The physical arm was designed using CAD with the goal of creating a functional robotic system that could perform controlled movement. I also designed the PCB required for the system.

Programming

I programmed the control logic in C++ using Microchip Studio. The code controlled the behaviour of the robotic arm and connected the embedded system with the physical hardware.

Skills Used

C++ Microchip Studio CAD PCB Design Embedded Systems Mechanical Design

Presentation

The completed project was presented as part of the course project evaluation at Dalhousie University.
