Breast Cancer Imaging Verification Tool

National Canadian Medical Datathon · Vancouver, BC
March 2026

For the Advanced Section of the National Canadian Medical Datathon, I worked on a diagnostic verification tool designed to scan breast ultrasound images using a provided dataset.

Project goal: Develop a tool that could assist medical professionals by providing an additional way to verify breast ultrasound findings. The project was designed for professional use rather than patient diagnosis.

What I Built

  • Created and trained an AI model using the provided breast ultrasound dataset.
  • Used Python to process the dataset and develop the model logic.
  • Used HTML to build the public-facing interface.
  • Connected dataset variables to the verification process.
  • Created a public website to demonstrate the project.

Engineering Challenge

One of the main challenges was translating medical dataset information into a system that could be used through a simple interface. This required combining programming, data organization, and an understanding of how the tool could fit into a medical workflow.

Presentation

I presented the proposed system and its application to judges and medical professionals during the competition.
