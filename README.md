# Gabrielle Ouellette — Portfolio

## GitHub Pages setup
1. Upload all files/folders in this directory to your GitHub repository.
2. Keep `index.html` at the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
4. Add your portrait at `assets/gabby.jpg`.
5. Replace/add project details as your projects develop.

The site is plain HTML/CSS/JS, so it works directly with GitHub Pages without a build step.
